# PM-OS for Mac

Download the PM-OS desktop app for Apple silicon Macs.

**[Download the latest version →](https://github.com/imuccini/pm-os-releases/releases/latest)**

## Install

1. Download `PM-OS-<version>-arm64.dmg` from the [latest release](https://github.com/imuccini/pm-os-releases/releases/latest).
2. Open it and drag **PM-OS** to **Applications**.
3. The app is not signed yet: the first time, right-click PM-OS in Applications and choose **Open**.

This repository only hosts the app's downloads.
