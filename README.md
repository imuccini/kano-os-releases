# Kano for Mac

Download the Kano desktop app for Apple silicon Macs.

**[Download the latest version](https://github.com/imuccini/kano-os-releases/releases/latest/download/Kano-arm64.dmg)** ·
[All releases](https://github.com/imuccini/kano-os-releases/releases)

Kano is agentic product management in your own GitHub repo. Learn more at [kano.pm](https://kano.pm), or try the
[live demo](https://app.kano.pm) in your browser.

## Install

1. Download `Kano-arm64.dmg` from the [latest release](https://github.com/imuccini/kano-os-releases/releases/latest).
2. Open it and drag **Kano** to **Applications**.
3. The app is not signed yet: the first time, right-click Kano in Applications and choose **Open**.

## Requirements

- A Mac with Apple silicon (M1 or later).
- `git`, which comes with the Xcode Command Line Tools (`xcode-select --install`). Kano checks for it when it starts.

## Updating

Download the latest release and replace the app in Applications. Release notes list what changed.

This repository only hosts the app's downloads.
